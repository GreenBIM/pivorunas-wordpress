# Pivorunas WordPress

The plugin is `pivorunas-portfolio`. The theme is `pivorunas`. Install steps are in SETUP.md.

Download this repository as a zip, then upload each folder in WordPress:

- Plugins, Add New, Upload: the `pivorunas-portfolio` folder, zipped
- Appearance, Themes, Add New, Upload: the `pivorunas` folder, zipped
