# Set this up on WordPress

You need WordPress 6.5 or newer.

1. Upload `pivorunas-portfolio` as a plugin and activate it.
2. Upload `pivorunas` as a theme and activate it.
3. Settings, Permalinks, choose Post name, and save.
4. Create pages About, Contact, and Links, using those slugs.
5. Appearance, Menus: Photos, Videos, About, Publications, Contact, Links. Assign it to Main menu.
6. Portfolio in the admin is where photographs, films, books, and the two home pictures are added.
