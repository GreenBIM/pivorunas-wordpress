Presentation theme for the Pivorunas portfolio. Requires the Pivorunas Portfolio plugin.

== Description ==

Draws the front page, the photo and video indexes, the frame viewer, and the book list.
Photographs, films, and books are stored by the plugin, so they remain if this theme is changed.

Named styles, in assets/css/site.css:

* .title
* .body
* .menu and .menu.is-active
* .menu-side and .menu-side.is-active

The header name is changed under Appearance, Customize, Site Identity.
