Series, films, and books for the Pivorunas site.

== Description ==

Stores the work. The Pivorunas theme draws it.

* A series is a title, a featured image for the side list, and photographs in order.
* A film is a title, a featured image, and an optional video file.
* A book is a title and a volume number.
* Two photographs for the front page live under Portfolio.

== Installation ==

1. Copy this folder into wp-content/plugins/.
2. Activate Pivorunas Portfolio.
3. Activate the Pivorunas theme.
4. Follow SETUP.md.
